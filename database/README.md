# Database

Schema được quản lý duy nhất bằng Flyway tại `boarding-house-backend/src/main/resources/db/migration`.

- `diagrams/`: sơ đồ ERD trong giai đoạn thiết kế tiếp theo.
- `seed/`: dữ liệu mẫu không nhạy cảm cho môi trường phát triển.
- `scripts/`: script hỗ trợ quản trị; không thay thế Flyway migration.
